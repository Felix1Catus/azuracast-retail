# Security policy

Report security problems in Acacia Radio privately to the maintainers of
https://github.com/Felix1Catus/azuracast-retail (GitHub: *Security* tab, *Report a vulnerability*), not in public
issues. Include the version (`/source` on the affected server shows it), what you found and how to reproduce it.

Problems in bundled third-party software (Icecast, Liquidsoap, MariaDB, nginx, PHP, spotDL, yt-dlp, ...) can be
reported to their own projects as well; we update them in the next release.
